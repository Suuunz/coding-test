# [프로그래머스] 가장 많이 받은 선물 (2024 KAKAO WINTER INTERNSHIP)

## 1. 문제 분석하기

### 문제 요약
- 친구 이름 배열 `friends`와 선물 기록 배열 `gifts`(`"준사람 받은사람"` 형태)가 주어진다.
- 규칙에 따라 다음 달에 선물을 주고받을 때, **가장 많이 받는 친구가 받을 선물의 수**를 구한다.

### 조건 정리
다음 달 선물은 **모든 두 사람 쌍(A, B)** 에 대해 아래 순서로 결정된다.

| 순서 | 조건 | 결과 |
| --- | --- | --- |
| 1 | A가 B에게 준 수 ≠ B가 A에게 준 수 | 더 많이 **준** 사람이 선물 1개를 받음 |
| 2 | 주고받은 기록이 없거나 수가 같음 | **선물 지수**가 더 큰 사람이 선물 1개를 받음 |
| 3 | 선물 지수까지 같음 | 아무도 받지 않음 |

- **선물 지수** = (내가 준 선물 수) − (내가 받은 선물 수)

### 필요한 정보 정리
규칙을 적용하려면 아래 두 가지 정보가 필요하다.
1. **두 사람 사이**에 누가 누구에게 몇 번 줬는지 → 사람 × 사람 표
2. 각 사람의 **선물 지수** → 사람별 값 하나

문제 예시에 나온 표가 그대로 힌트가 된다.

### 알고리즘 / 자료구조 선택
- 이름(문자열)을 표의 인덱스(숫자)로 바꿔야 한다 → **HashMap<String, Integer>**
- 두 사람 사이의 선물 횟수 → **2차원 배열 `int[][]`**
- 사람별 선물 지수 → **1차원 배열 `int[]`**
- 모든 쌍을 비교하며 규칙을 적용 → **완전 탐색(이중 반복문) + 구현**

### 입력 크기 확인
- 친구 수 N ≤ 50 → 모든 쌍을 비교해도 50 × 50 = 2,500번
- 선물 기록 G ≤ 10,000 → 한 번씩만 훑으면 됨
- 단순 반복으로 충분하다.

## 2. 선택한 알고리즘, 자료구조

### HashMap
- **Key–Value** 쌍으로 데이터를 저장하는 자료구조로, key로 value를 평균 **O(1)** 에 찾을 수 있다.
- 이 문제에서는 `"muzi" → 0`, `"ryan" → 1`처럼 **이름을 배열 인덱스로 변환**하는 용도로 사용한다.
- 주요 메서드: `put(key, value)`, `get(key)`

### 2차원 배열
- `int[][] arr = new int[N][N]` 형태로, 행과 열로 이루어진 표를 표현한다.
- `giftCount[i][j]` = **i가 j에게 준 선물 수**로 정의하면
    - `giftCount[i][j]`와 `giftCount[j][i]`를 비교해 두 사람 중 누가 더 많이 줬는지 바로 알 수 있다.

### 완전 탐색
- 가능한 모든 경우를 빠짐없이 확인하는 방법이다.
- 입력 크기가 작을 때(N ≤ 50) 가장 단순하고 확실한 방법이다.

### String.split
- `"muzi frodo".split(" ")` → `["muzi", "frodo"]`
- 공백 기준으로 준 사람과 받은 사람을 분리할 때 사용한다.

## 3. 전략 세우기

### (1) 이름 → 인덱스 매핑
`friends` 순서대로 번호를 붙여 HashMap에 저장한다.

```
muzi → 0, ryan → 1, frodo → 2, neo → 3
```

### (2) 선물 기록 정리 (표 만들기)
`gifts`를 하나씩 보면서
- `giftCount[준사람][받은사람]++`
- `giftIndex[준사람]++` (준 선물이므로 지수 +1)
- `giftIndex[받은사람]--` (받은 선물이므로 지수 −1)

> 준 수와 받은 수를 따로 세지 않고, 지수 배열 하나에서 바로 더하고 빼면 된다.

### (3) 다음 달 받을 선물 수 계산
각 사람 `i`에 대해 자신을 제외한 모든 `j`와 비교한다.

```
if (i가 j에게 준 수 > j가 i에게 준 수)        → i가 받음
else if (두 수가 같고, i의 지수 > j의 지수)     → i가 받음
```

- i 입장에서 **"내가 받는 경우"만 세면** 된다.
- j가 받는 경우는 j 차례에서 따로 세어지므로 중복이 생기지 않는다.
- 선물 지수까지 같으면 둘 다 조건에 걸리지 않으므로 자동으로 "주고받지 않음"이 처리된다.

### (4) 최댓값 구하기
사람마다 센 값 중 **가장 큰 값**을 정답으로 저장한다.

## 4. 코드 구현하기

### 구현 순서
1. `n = friends.length`
2. `HashMap<String, Integer>`에 이름 → 인덱스 저장
3. `int[][] giftCount = new int[n][n]`, `int[] giftIndex = new int[n]` 생성
4. `gifts`를 순회하며 `split(" ")`으로 분리 → 표와 지수 갱신
5. 이중 반복문으로 각 사람 `i`가 받을 선물 수 `count` 계산 (`i == j`는 건너뜀)
6. `answer = Math.max(answer, count)`
7. `answer` 반환

### 시간 / 공간 복잡도
- 시간: 선물 기록 정리 **O(G)** + 모든 쌍 비교 **O(N²)** → **O(G + N²)**
- 공간: 2차원 배열 **O(N²)**

---



### 정리
- 이름은 그대로 쓰기 불편하므로 **HashMap으로 인덱스로 변환**한 뒤 배열을 사용한다.
- 문제 예시의 표를 그대로 **2차원 배열(주고받은 수) + 1차원 배열(선물 지수)** 로 옮기면 된다.
- 각 사람 입장에서 **"내가 받는 경우"만 세면** 중복 없이 모든 쌍을 처리할 수 있다.
- 주고받은 기록이 없는 경우(0 = 0)도 "수가 같은 경우"에 자연스럽게 포함된다.
